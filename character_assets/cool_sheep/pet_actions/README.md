# Cool Sheep Pet Actions

Codex desktop pet style action images for the sheep/ram character.

## Recommended folder

Use `pet_ready_1024x1536/` for implementation.

These files are transparent PNGs with a consistent 1024x1536 canvas:

- `01_idle.png` - idle / waiting
- `02_wave.png` - greeting
- `03_thinking.png` - thinking
- `04_working_laptop.png` - working / coding
- `05_success.png` - success / completed
- `06_confused_error.png` - confused / error
- `07_pointing.png` - presenting / guiding
- `08_sleeping.png` - sleep / inactive
- `09_running.png` - busy / hurrying

## Other folders

- `source_chromakey/`: original generated images on green chroma-key background.
- `transparent/`: transparent PNGs before canvas normalization.

## Review sheets

- `pet_actions_contact_sheet.png`: transparent originals.
- `pet_ready_1024x1536_contact_sheet.png`: normalized pet-ready set.
